编程智能体（DeepSeek 驱动）

一、仓库地址
https://github.com/Charliehua12/nju-se-coding-agent

二、如何运行
1. 环境：Python 3.10+，无需安装任何第三方库（仅用标准库）。
2. 配置密钥：复制 .env.example 为 .env 填入 DEEPSEEK_API_KEY，
   或 export DEEPSEEK_API_KEY=...。
3. 运行：python main.py "任务描述"；不带参数则进入交互对话模式（多会话可切换）。
   可选：--workdir 指定工作目录；--max-iter 最大步数；--ask 命令前人工确认。

三、特色功能
1. 零第三方依赖：连 HTTP 层、流式解析、token 估算均为标准库自写，
   不依赖任何 agent 框架/SDK。
2. 审查模式（--approve 或 /approve）：写/改/删文件、执行命令前逐个
   展示 diff 并请求你的许可，可拒绝或留言；相同调用有缓存不重复打扰；
   改动全程留痕，可 /review 查看与回滚。
3. 工具本地沙箱执行：读写文件、定点编辑、搜索、执行命令，带路径越界
   防护、命令超时与输出截断。
4. 上下文管理：token 预算 + 三级压缩（截断工具输出、LLM 摘要、兜底
   丢弃）+ 过载保护（消息长度/数量上限）。
5. 交互式多会话：REPL 内可 /new /switch /del 多个独立会话，/save /load
   支持单会话或全量持久化，跨进程恢复。
6. 错误自愈：命令失败、参数非法、审批被拒等结果回喂模型，使其自主修正。
6. 计划先行：先制定计划，需人工确认（可多轮修改/重拟/取消）后才执行。
7. Markdown 终端渲染：自写纯标准库的 Markdown→ANSI 渲染器，流式按行缓冲。
8. 终止条件：无工具调用即完成、达最大步数收尾、异常退出。

四、架构
核心为「思考→行动→观察」循环：system+任务 → 调模型 → 解析 tool_calls
→ 本地执行 → 结果回填 → 循环，直至模型不再调用工具。
